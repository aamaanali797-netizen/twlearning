# Google Docs

Google Docs is a cloud-based word processor by Google. Its main advantage over traditional tools like MS Word is real-time collaboration — multiple people can edit the same document at the same time.

## Key Features

- Real-time collaboration with multiple users
- Auto-saves everything to Google Drive
- Version history to track and restore changes
- Commenting and suggestion mode
- Works in any browser, no installation needed

## Creating and Sharing

- Go to docs.google.com and create a new document
- Click Share to add collaborators
- You can set permissions: Viewer, Commenter, or Editor
- Can also share via link with anyone

## Formatting

Google Docs supports standard formatting:
- Headings (H1, H2, H3 etc) for document structure
- Bold, italic, underline
- Bulleted and numbered lists
- Tables and images
- Headers, footers, and page numbers

## Collaboration Features

- **Suggesting mode**: edits show up as suggestions that others can accept or reject
- **Comments**: click on text and add a comment, tag people with @
- **Version history**: go to File > Version history to see all changes and who made them
- **Assign action items**: use comments to assign tasks to team members

## Tables and Images

- Insert > Table to add tables
- Insert > Image to add pictures from upload, URL, Drive, or Google Photos
- Can also insert drawings and charts

## Equations

Insert > Equation lets you type basic math formulas. It supports LaTeX-style input through the GUI.

For code snippets, use a monospace font or paste as preformatted text.

## Citations and Bibliography

- Tools > Citations to add sources
- Supports MLA, APA, and Chicago formats
- Can generate bibliography automatically
- Also works with Zotero and Mendeley via add-ons

## Exporting

Download as:
- PDF
- DOCX (Word)
- ODT
- HTML
- Plain text

You can also publish to web for public viewing.

## Integration with Other Tools

- Google Drive for file storage
- Google Sheets and Slides
- Google Calendar and Meet
- Third party tools like Trello, Asana via add-ons
- Google Apps Script for automation

## Best Practices

- Use headings consistently for structure
- Add a table of contents for longer docs
- Use templates for reports and proposals
- Clean up resolved comments regularly
- Export important versions as PDF for backup

## Doxygen vs Google Docs

| Feature | Doxygen | Google Docs |
|---------|---------|-------------|
| Purpose | Code/API docs | General documents |
| Collaboration | Indirect (code reviews) | Real-time multi-user |
| Output | HTML, LaTeX, PDF | Web, PDF, Word |
| Best for | Source code, APIs | Reports, proposals, notes |

Use Doxygen for code documentation and Google Docs for everything else. Both can be used together in a project.
